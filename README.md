# Portfolio Profesional

Este repositorio contiene el código fuente de mi portfolio profesional desarrollado con **React + Vite**, desplegado en **GitHub Pages**.

## 🔍 Tecnologías utilizadas

- React
- Vite
- Tailwind CSS
- GitHub Pages
- Google Analytics 4
- Google Tag Manager (GTM)

## 📊 Seguimiento con Google Analytics

Implementé seguimiento personalizado en el sitio mediante:

- Configuración de **Google Tag Manager**
- Activación de eventos personalizados como `click_cv`
- Medición de clics en el botón de descarga del CV
- Visualización de eventos en tiempo real desde Google Analytics
